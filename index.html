✅ الإجابة:

العلاقة عكسية: كلما ارتفعت عن سطح البحر، قلّ الضغط الجوي. لأن عمود الهواء فوقك أصبح أقصر وأخف.

على سطح البحر: الضغط ≈ 1013 hPa.
على قمة إيفرست (8848م): الضغط ≈ 337 hPa — ثلث القيمة فقط!

بمعادلة فيزيائية بسيطة، ESP32 يحوّل الضغط إلى ارتفاع دقيق. لهذا الطائرات والمسّاحون يستخدمون مقياس الارتفاع البارومتري.

🔬 ما هو BME280؟

03 / 11

💡 ثلاثة في واحد

BME280 ليس حساساً واحداً — بل ثلاثة حساسات في شريحة صغيرة بحجم ظفر الإصبع:

🌡️ حرارة — من -40° إلى +85° (دقة ±1°)
💧 رطوبة — نسبة بخار الماء في الهواء (0-100%)
📊 ضغط جوي — من 300 إلى 1100 hPa

🎯 الميزة القاتلة

⛰️

من الضغط نحسب الارتفاع!

هذه هي المعادلة الفيزيائية التي سنستخدمها:

altitude = 44330 × (1 - (P/1013.25)^0.19)
🎯 لماذا هذا مذهل؟ في مشروع واحد — إنترنت + ساعة + طقس + ارتفاع. كل هذا من شريحة بحجم 2 سم وبسعر أقل من فنجان قهوة ☕.

⚠️ تحذير حرج

🛡️ 3 قواعد مهمة

05 / 11
⚡ تحذير 1 — الجهد:

BME280 يعمل بـ 3.3V. توصيله بـ 5V يُتلفه فوراً. هذه هي نفس القاعدة الذهبية لـ ESP32 — نصف مكوناتنا تعمل بـ 3.3V.

⚠️ تحذير 2 — لا تلمسه:

الحساسات الدقيقة داخل BME280 تتأثر بزيوت الأصابع وحرارة الجسم. لو لمسته مباشرة، القراءات ستنحرف لثوانٍ.

⚠️ تحذير 3 — الرطوبة المباشرة:

رغم أن BME280 يقيس الرطوبة، فإنه لا يتحمل الماء السائل. لا تضعه في مكان قد يتبلّل — استخدم غلافاً واقياً في المشاريع الخارجية.

💡 نصيحة عملية: ضع BME280 بعيداً عن ESP32 نفسه — لأن ESP32 يسخن قليلاً أثناء العمل، وقد يؤثر على قراءة الحرارة. 5 سم كافية.

Sketch → Include Library → Manage Libraries → ابحث عن BME280 → اختر نسخة Adafruit → Install.

🧪 الكود 1: قراءة أولية

07 / 11

قبل OLED، نتأكد أن BME280 يعمل ونقرأ الثلاث قيم على Serial Monitor.

#include <Wire.h>
#include <Adafruit_BME280.h>

Adafruit_BME280 bme;   // كائن الحساس

void setup() {
  Serial.begin(115200);

  if (!bme.begin(0x76)) {       // جرّب 0x77 إن فشل
    Serial.println("BME280 not found!");
    while (1);
  }
  Serial.println("BME280 Ready!");
}

void loop() {
  float t = bme.readTemperature();  // °C
  float h = bme.readHumidity();     // %
  float p = bme.readPressure() / 100.0F;  // hPa

  Serial.print("Temp: ");
  Serial.print(t, 1);
  Serial.print(" C | Hum: ");
  Serial.print(h, 1);
  Serial.print(" % | Press: ");
  Serial.print(p, 1);
  Serial.println(" hPa");

  delay(2000);
}
✅ القيم المتوقعة: Temp ~25°C, Hum ~50%, Press ~1013 hPa
❌ لو ظهر "not found": جرّب العنوان 0x77 أو تحقق من التوصيل

🌤️ الكود 2: محطة طقس + مقياس ارتفاع

#include <Wire.h>
#include <Adafruit_BME280.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_W 128
#define SCREEN_H 64
#define OLED_ADDR 0x3C
#define SEA_LEVEL_HPA 1013.25

Adafruit_BME280 bme;
Adafruit_SSD1306 display(SCREEN_W, SCREEN_H, &Wire, -1);

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);

  if (!bme.begin(0x76)) {
    Serial.println("BME280 failed!");
    while (1);
  }

  display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR);
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.println("BME280 Ready");
  display.display();
  delay(1000);
}

void loop() {
  float t = bme.readTemperature();
  float h = bme.readHumidity();
  float p = bme.readPressure() / 100.0F;
  float alt = bme.readAltitude(SEA_LEVEL_HPA);  // متر

  display.clearDisplay();

  // العنوان
  display.setTextSize(1);
  display.setCursor(0, 0);
  display.println("== Weather Station ==");

  // الحرارة
  display.setCursor(0, 14);
  display.print("T: ");
  display.print(t, 1);
  display.println(" C");

  // الرطوبة
  display.setCursor(0, 26);
  display.print("H: ");
  display.print(h, 1);
  display.println(" %");

  // الضغط
  display.setCursor(0, 38);
  display.print("P: ");
  display.print(p, 1);
  display.println(" hPa");

  // الارتفاع (كبير)
  display.setTextSize(2);
  display.setCursor(0, 52);
  display.print((int)alt);
  display.println(" m");

  display.display();
  delay(2000);
}
🎯 3 أفكار مفتاحية:

bme.begin(0x76) — العنوان I2C (جرّب 0x77 إن فشل).
readPressure() / 100.0 — التحويل من Pa إلى hPa.
readAltitude(1013.25) — يحسب الارتفاع من الضغط تلقائياً!
